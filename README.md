# Math Adventure · math-adventure

面向 3–6 岁幼儿的数学启蒙游戏。纯静态网页，原生 HTML / CSS / JS，无框架、无构建、无后端。
**全英文沉浸式**：所有语音、教学与界面文案均为英文。

线上预览：https://lipinglabs.github.io/math-adventure/
添加到主屏幕即可获得独立图标（`manifest.json` + `icons/`）。

## 现在能玩到什么

- 地图：按 5 大阶段分页（一屏一阶段，超过 6 关左右滑动），底部 `◀ ▶` 切阶段，支持星级与解锁状态；
- **Level 1 · Apple Addition**：3 幕动画教学（落体 / 挤压回弹 / 点数 / 认识加号）+ 10 道题；
- **Level 2 · Balloon Take Away**：3 幕教学（气球飘走 / 点数 / 认识减号）+ 10 道打乱顺序的减法题；
- **Level 3 · Orchard Harvest**：3 幕果园教学（小鸟送苹果 / 风吹落果 / 加减号）+ 10 道混合题，
  含「选符号 / 选算式 / 选结果」三种题型；
- **Level 4 · Ten and Some More**：十格阵教学（满十 / 认识 13 / 凑 16）+ 10 道题，
  凑数题要按绿色对勾提交（放多了可点苹果拿回，铁律 §6.10）；
  含「看阵识数 / 听数选阵 / 拖拽凑数」三种题型；
- **Level 5 · Cookie Party**：发饼干场景教学（装满一盒 10 块 / 认识 15 / 发 18 块）+ 10 道题，
  发饼干题同样要按对勾提交，允许放多、点饼干可拿回；
  含「听数字拖饼干 / 看盒点数字 / 选对应小动物」三种题型；
- **Level 6 · Number Link**：2 幕连线教学（13 ↔ 十格阵 / 找 16）+ 10 道题，
  含「数字连阵图 / 听音连数字 / 看图选数」三种题型；
- **Level 7 · Block Build**：3 幕积木教学（12+3 的构成 / 个位相加 / 竖式规律）+ 10 道题，
  含「看积木点总数 / 听算式选组合 / 横式拖数字填空」三种题型，一律不进位；
- **Level 8 · Car Garage**：3 幕车库教学（认识车库 / 车进个位库 / 竖式规律）+ 10 道题，
  含「拖车进库再点总数 / 听算式选车库 / 横式点数字」三种题型，一律不进位；
- **Level 9 · Quick Tap**：2 幕纯数字教学（积木变算式 / 个位速算）+ 10 道题，
  含「看算式点答案 / 找错误算式 / 5 秒闪电点选」三种题型；
- **Level 10 · Bird Branch**：3 幕树枝教学（认识 18 / 飞走 5 只 / 竖式规律）+ 10 道题，
  含「看鸟飞走点剩余 / 听总数选树枝 / 点掉指定数量再点剩余」三种题型，一律不退位；
- **Level 11 · Candy Share**：3 幕糖果教学（认识 18 / 拿走 5 颗 / 竖式规律）+ 10 道题，
  含「拖糖进盘再点剩余 / 听总数选糖果组 / 找错误算式（答对后演示改正）」三种题型，一律不退位；
- **Level 12 · Lightning Math**：2 幕纯数字教学（积木剥离成算式 / 竖式规律）+ 10 道题，
  含「纯算式点选 / 算式卡 + 气球选答案 / 5 秒闪电心算」三种题型，一律不退位；
- **Level 13 · Mix It Up**：二阶大复习，2 幕教学（加减并排对比，积木飞入 / 飞走；十格阵变数字）+ 10 道题，
  含「不进位加法点选 / 不退位减法点选 / 看图选数」三种题型，全部纯点选；
- **Level 14 · Match Maker**：2 幕拖拽示范教学（手把 12+3 拖到 15 / 18−5 拖到 13，吸附发光）+ 10 道题，
  含「算式拖到数字 / 听音挑一张再拖 / 反向挑算式」三种题型，全部拖拽配对；
- **Level 15 · Final Challenge**：二阶结业挑战，2 幕教学（三连回顾 / 亮出二阶奖杯）+ 10 题混排大考
  （听音点选 / 看积木拖拽 / 找错误算式）；**金星后播放二阶结业仪式**——彩带、金色奖杯、STAGE 2 绶带与专属语音；
- **Level 16 · Make Ten**：第三阶段开场（满十进一）。3 幕教学：9 个红苹果 + 4 个蓝苹果 → 飞 1 个进第 10 格
  → 满十发光并打包成一整盒（金色封边 + 「10」标签）→ 竖式里进位币飞进十位、十位的 1 高亮闪烁；
  10 题三型：看凑十动画点结果 / 自己拖苹果凑满十格阵再答总数 / 找错误算式；
- **Level 17 · Corn Basket**：小猴子搬玉米。3 幕教学：筐里 8 个玉米 + 地上 5 个 → 搬 2 个凑满（筐发光并打包）
  → 拆数链 `8 + 5 = 8 + 2 + 3 = 10 + 3 = 13`；10 题三型：拖玉米填满筐再点总数 / 听算式选对应的那筐 /
  点出拆分里缺的那个数；
- **Level 18 · Split It**：把「拆数凑十」单独练。3 幕教学：`8 + 5` 配两个十格阵 → 数字 5 被劈成 2 和 3
  → 竖式里 2 飞向 8 凑成 10；10 题三型：分步填空（先填凑十要几个、再填还剩几个）/ 听算式点出对应的拆解图 /
  直接点选结果；
- **Level 19 · Break the Ten**：破十法（退位减法）。3 幕教学：一捆十根 + 三根零散 → 解开那捆散成十三根、
  拿走九根剩四根 → 竖式 `13 − 9 = 4`，13 拆成 10 和 3；10 题三型：点开那捆、拖走 b 根再点剩余 /
  听算式点出对应的破十过程 / 找错误算式；
- **Level 20 · Borrow a Ten**：借十法（退位减法）。3 幕教学：果篮里一个十 + 右边两个 = 十二 →
  小人跑到果篮前把那个十拖到个位垫、散成十个一（共十二个）→ 竖式 `12 − 8 = 4`，十位的 1 借走变 0、个位的 2 变成 12；
  10 题三型：把果篮里的十拖出来散开、拿走 b 个再点剩余 / 听算式点出对应的拆分图 / 找错误算式；
- **Level 21 · Flash Math**：闪电心算（退位减法）。2 幕教学：一捆十根 + 三根、旁边竖式 `13 − 9 = ?` → 解捆、
  拿走九根、剩四根 → 竖式收起（十位 1 划掉补 0、个位 3 划掉补 13）+ 闪电徽标；
  10 题三型全部限时 5 秒：纯算式点选 / 气球选结果 / 限时找错误算式；
- **Level 22 · Line Them Up**：竖式对齐。4 幕教学：2 捆 + 3 根 与 1 捆 + 5 根 → 个位合流成 8 根 →
  十位合流成 3 捆 → 竖式 `23 + 15` 数字飞进各自的位；10 题三型：听算式点结果 / 六个数字拖进竖式 /
  三个竖式找错（没对齐或算错）；
- **Level 23 · Market Day**：超市购物。4 幕教学：苹果 24 + 面包 13 → 问「How much in total?」停 1 秒自答 →
  钱币飞进收银台变 37 → 竖式；10 题三型：问总价点选 / 小票拖总价 / 三张清单找错价；
- **Level 24 · Number Maze**：终极运算迷宫。4 幕教学：猫在门口遇 `25 + 12` → 三个出口（37/35/39）问「Which way?」
  停 1 秒自答 → 连算 `30 + 15 − 10` 两拍（先 45 后 35）→ 终点；10 题三型：门口算结果 / 连算拖结果 / 三条路找错；
- **Level 25 · Addition Adventure**：进位加法大复习。4 幕教学：十格阵 8 红 + 6 绿 → 2 个绿飞进去凑满十 →
  6 拆成 2 和 4 → 竖式 `8 + 6 = 14`；10 题三型：点结果 / 凑十链四空拖拽 / 三算式找错；
- **Level 26 · Subtraction Safari**：退位减法大复习。4 幕教学：1 捆 + 4 根 → 解捆拿走 8 根 →
  `10 − 8 = 2`、`2 + 4 = 6` → 竖式 `14 − 8 = 6`；10 题三型：点结果 / 破十链三空拖拽 / 三算式找错；
- **Level 27 · Stage 3 Finale**：三阶结业挑战。4 幕教学：9+5 与 14−8 并排演示 → 大奖杯升起 →
  奖杯定格 → 最终挑战邀请；10 题完全混排（加 3 / 减 4 / 挑错 3）；金星触发三阶结业仪式（24 条彩带 +
  金色奖杯 + STAGE 3 绶带 + 专属语音），落幕后留下常驻徽章；
- **Level 28 · Magic Gloves**：2 的乘法。4 幕教学：3 双手套逐只点数到六 → 三个 2 飞进圈（2+2+2=6）→
  3 × 2 = 6 → 两种读法同屏；10 题三型：看阵列点结果 / 拖手套拼阵列 / 三算式找错；
- **Level 29 · Candy Strings**：5 的乘法。4 幕教学：3 串糖果 → 逐颗点数 5·10·15 → 3 × 5 = 15 →
  跳跃数列；10 题三型：看糖串点结果 / 拖糖串拼阵列 / 纯听速算；
- **Level 30 · Quick 2s & 5s**：口诀速算。4 幕教学：2×6 六步跳跃 → 十格阵按 2 点满十二 →
  5×4 四步跳跃 → 两句口诀同屏；10 题三型：纯数字点选 / 气球选结果 / 五秒闪电；
- 连线一笔画出（拖拽或两下轻点都可），连错画红线 560ms 后收回、不锁题；
- 积木落地有挤压回弹（`scale(1.16,.74) → scale(.94,1.08) → scale(1)`），整排下方带柔和落影；
- 选择题选项数按题型分级（2 / 3 / 4，见铁律 §6.5），答错立即重排；
- 拖拽热区比视觉大一圈（四边外扩 14px），拖歪了平滑弹回、不误放；
- 卡片配对有「咔哒」吸附（飞入 + 挤压回弹 + 双卡发光），轻点两下也能配（拖拽的触屏兜底）；
- 阶段结业关（L15）通关金星后有全屏结业仪式：24 条彩带 + 奖杯升起 + STAGE 2 绶带 + 专属语音，落幕后留下常驻徽章；
- 进位加法用「凑十」讲：十格阵填满那一格会发光，整框随即被金色封边打包成「一个十」，竖式里再用进位币把十送进十位；
- 凑十还能拆着讲：`8 + 5` 把 5 拆成 2 和 3，一枚「2」飞向 8 凑成 10，再把剩下的 3 加上（L17 的拆数链、L18 的劈数字）；
- 一个算式能拆成两半填空：先填「凑十要几个」、再填「还剩几个」，第一空填对了才轮到第二空，用掉的数字键会压暗；
- 退位减法用「破十」讲：个位不够减就把那捆十解开，十根散开后再一根一根拿走（L19）；
- 退位减法也能「借十」讲：果篮里的整十被拖到个位垫上散成十个一，再一个一个拿走（L20）；
- 同一套借十法最后推到纯数字：题干播完才开 5 秒条，剩余不足 40% 转红，超时或点错原地重做、条回满（L21）；
- 两位数加法靠「竖式对齐」讲：个位对个位、十位对十位，数字飞进各自的列（L22）；再放进超市与小票（L23）；
- 乘法先用「一个单位 = 一个可数实体」讲：一双手套是两个、一串糖是五个，再收成 `×`（L28–L29）；\n- 口诀先数再背：2 按 2·4·6…、5 按 5·10·15… 跳着数，最后才做五秒闪电（L30）；
- 连算拆成两拍：先算前一步、再算后一步，猫沿迷宫走一步（L24）；
- 第三阶段收尾：进位加法用凑十链、退位减法用破十链各复习一遍，最后一场混排结业挑战（L25–L27）；
- 每一关都挂一张专属背景照片（`assets/bg/bg_01.jpg` … `bg_48.jpg`，一关一张）：最长边 1024、blur 3px、
  JPEG q80、剥掉 EXIF，按关加载、二次进入走缓存；照片上叠白色蒙版，只做若隐若现的水印；
- 动画遵循现实规则：气球飞走后其余气球留在原位，不会重新排布；
- 10 题全对得 Gold Star 并解锁下一关；中途答错原地重做，得 Silver Star；
- 云存档（Gist）、开发者沙盒（左上角连点 5 次，口令 123）；
- 素材本地持久化：同一设备第二次进入关卡不再下载、不再弹读条。

## 本地运行

```bash
python -m http.server 8765 --bind 127.0.0.1
# 打开 http://127.0.0.1:8765/index.html
```

验收参数：

- `?quick=1`：跳过教学直接进题
- `?demo=loader`：伪造素材，演示加载进度条
- `?demo=fail`：演示加载失败与重试

## 语音

由豆包语音合成 2.0（Allison，语速 0.85）在构建期生成独立 mp3，运行时不调用任何外部接口。

```bash
python tools/gen_tts.py voice/lines/lv01.json --out voice/lv01 --dry-run   # 校验
python tools/gen_tts.py voice/lines/lv01.json --out voice/lv01             # 生成
```

密钥只从 `DOUBAO_API_KEY` 环境变量或本机 `config/secrets.local.json` 读取，绝不入库。

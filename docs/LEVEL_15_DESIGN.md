## 3. 题型（10 题完全随机混排）

### 类型 1 · 听音点选（4 题）

- 屏幕中央 `15 + 3 = ?`（数字整块），下方三个数字键。
- 点对：结果格填上并转绿，700ms 后进下一题；点错：摇晃 + `try_again`（每题一次）+ 三个键重排。

### 类型 2 · 看图拖拽（3 题）

- 左边一张积木卡（一捆十块 + 5 / 3 / 8 块零散），右边三张数字卡。
- 拖积木卡到正确数字上：§5.14 的吸附（飞入 170ms + 挤压回弹 + 双卡发光 + 对勾）。
- 拖歪了 320ms 弹回、不判错；轻点积木再点数字也能配上。

### 类型 3 · 找错误算式（3 题）

| 题 | 三句 | 错在哪 |
|---|---|---|
| 1 | 11+4=15 / 16−3=13 / **19−5=15** | 真值 14（差 +1） |
| 2 | 12+5=17 / 18−4=14 / **13+4=15** | 真值 17（差 −2） |
| 3 | 11+6=17 / 18−6=12 / **12+4=18** | 真值 16（差 +2） |

- 三句里恰好一句不成立，错法各不相同（不是清一色差 1）。
- 点对：卡片转绿 + 白勾，随后**只把结果格翻一下**换成正确答案，定格 1.5 秒（§6.11）。
- 点错（点到成立的那句）：摇晃 + `try_again` + 三句重排。

## 4. 二阶结业仪式（§6.13）

金星结算后 520ms 叠加一层全屏仪式：

| 元素 | 实现 |
|---|---|
| 底色 | 暖色径向渐变（`radial-gradient`），从浅奶油到蜜金 |
| 光芒 | 470px 的 `repeating-conic-gradient` 圆盘，16s 匀速旋转，透明度 0.62 |
| 光晕 | 300px 径向渐变，2.4s 呼吸 |
| 脉冲环 | 两个圆环从 0.35 倍扩到 1.55 倍并淡出 |
| 彩带 | **24 条**，颜色 / 宽高 / 落速（2.3–3.6s）/ 延迟（0–720ms）/ 漂移 / 旋转各不相同，只跑 `transform` + `opacity` |
| 奖杯 | 186 × 216，`l15-rise` 从下方弹起，静态 `drop-shadow` 柔光 |
| 火花 | 6 颗四角星，1.8s 错峰闪烁 |
| 绶带 | `STAGE 2` 药丸，400ms 后弹入 |
| 专属语音 | `common/gold` 播完后播 `win`，两句不叠 |

收起方式：出现 1.2 秒后可点掉；否则在 `win` 播完 0.9 秒后自动淡出（约 4 秒）。
收起后在结算页星星下方留一枚常驻 `STAGE 2` 小徽章（奖杯图标 + 文字）。

## 5. 实现要点

| 位置 | 做法 |
|---|---|
| 混合出题 | `queue = Engine.quiz.shuffle(questions)`，10 题整份打乱，题型不相邻固定 |
| 拖拽 | 复用 §5.14：`HIT_PAD = 14`、ghost 跟随、命中飞入、未命中弹回；`state.done` 挡二次拖拽 |
| 找错句 | 三句 `value(a,b,op) !== shown` 的恰好一句；答对 `correct(card, 1500)` + `showFix()` 翻结果格 |
| 仪式触发 | `finish(star)` → `LevelKit.showResult` → 仅 `gold` 时 `ceremony(starVoice)` |
| 语音串联 | `LevelKit` 的 `play` 回调用 `starVoice = ctx.audio.play(key)` 接住 promise，仪式里 `.then` 再播 `win` |
| 清理 | `unmount()` 移除 `.l15-ghost` 与 `.l15-ceremony`；`askQuestion()` 开头兜底清 ghost |

## 6. 验收结果（2026-10-29）

- 语音 12 条关内 + 4 条公共，全部可解码，合计 **55.7 秒 / 436 KB**（关内 43.9 秒 / 344 KB）。
- 三型：点选 4 题（18 / 16 / 12 / 17 全中）、拖拽 3 题（15 / 13 / 18 全中）、找错 3 题
  （19−5=15、13+4=15、12+4=18，答对后分别翻成 14 / 17 / 16，定格 1.5 秒后换题）。
- 拖拽热区：数字卡右边界外 **16px** 不落子不判错，外 **13px** 命中；ghost 结束后清零。
- 10 题全对 → `gold`、`unlockedLevel = 16`，**结业仪式出现**：彩带 24 条、奖杯 1 只、`STAGE 2` 绶带、
  `win` 只播 1 次；约 4 秒后仪式层消失并留下 `STAGE 2` 徽章。
- 错一题 → `silver`、`unlockedLevel = 15`，**无仪式层**。
- 布局：390 / 375 宽都 `scrollWidth === innerWidth`；零 CJK（含 `aria-label`）。
- 地图：Stage 2 扩到 12 关后仍是 2 页（6 + 6），第 15 关在第 2 页最上面，标签 `Final Challenge`。
- 缓存：清空后首进读条（12 个音频 / 344 KB），二次进入 `voiceReqs = 0`、读条不出现。

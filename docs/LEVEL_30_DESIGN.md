## 答题

- **A（4）**：`2×7 / 5×6 / 2×8 / 5×3`，只有算式与三键。
- **B（3）**：算式卡 + 三只气球（红 / 蓝 / 绿），球面印数字；答对后结果格翻成积。
- **C（3）**：`5×5 / 2×4 / 5×7`，5 秒条；**题干播完才开走**（§6.9），播报期间 `is-idle`。

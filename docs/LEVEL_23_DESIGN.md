## 1. 教学四幕

| 幕 | 画面 | 语音 |
|---|---|---|
| 1 | 货架：苹果价签 24、面包价签 13，下方收银台显示 `?` | `t1_a` + `t1_b` |
| 2 | 收银台翻成 37（绿色） | `t1_q` How much in total? → **停 1 秒** → `t1_c` |
| 3 | 两枚钱币（24 / 13）依次飞进收银台，屏幕从 0 变 37 | 无语音（纯动画 + 音效） |
| 4 | 横式 `24 + 13 = 37` + 竖式对齐 | `t1_d` Line up the numbers. The total is thirty-seven. |

> 第二幕把问句与自答放在同一幕内，避免「问句悬空等点击」（§6.1）。

## 2. 答题十题

| 型 | 题数 | 玩法 |
|---|---|---|
| `shop` | 4 | 两件商品 + 价签，听 `What is the total?` 点总价 |
| `receipt` | 3 | 小票缺总价，把正确数字拖进空格；拖错弹回不改小票 |
| `wrong` | 3 | 三张清单，点出总价算错的那张；只翻总价格并定格 1.5 秒 |

题目：24+13=37 / 32+15=47 / 21+14=35 / 43+12=55；清单三组错价（36 vs 35 / 56 vs 55 / 58 vs 57）。

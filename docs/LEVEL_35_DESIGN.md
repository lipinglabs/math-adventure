## 两种证明（§5.22）

1. **旋转**：同一批 12 块节点整体 `rotate(90deg)`，`188×140 → 140×188`，装在 236×236 舞台里。
2. **重新装盘**：草莓节点一个不换，只把 2 个盘子换成 3 个盘子；用 FLIP 让每颗草莓从旧位置滑到新位置
   （单颗位移 ≤60px），总数徽标 `6 berries` 全程不消失。

## 答题

- **A（4）**：`4×5 / 3×6 / 5×4 / 2×7` 的阵列，三个选项各是一对算式，只有一组两式都等于总数。
- **B（3）**：`3×8=[ ]×3`、`5×7=[ ]×5`、`4×9=[ ]×4`，单空 + 4 个候选数字。
- **C（3）**：听 `6×4 / 7×3 / 9×2`，从 `×` / `+` 混排的三张里选等价的那张（选项不含原顺序）。

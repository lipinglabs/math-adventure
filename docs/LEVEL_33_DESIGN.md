## 转盘设计

- `<svg viewBox="0 0 320 320">`：9 个 40° 扇区（`A` 弧拼整圆），半径 150，扇区中心半径 112 放数字 1–9。
- **指针钉在 12 点不转**；转的是整块盘面（`.l33-svg` 加 `rotate`），目标角 `-(n-1)*40 + 360*3`。
- 中心盘是独立 DOM（`.l33-hub`），不随盘转；`×3` / `×4` 用 `rotateX` 翻牌切换。
- 时长 1000 ms、`cubic-bezier(.16,.84,.3,1)`；落定后把 `rotate(...)` 写进内联样式。
- 实测：扇区 9、数字 1–9 各一次、`4 → rotate(960deg)`、`5 → rotate(560deg)`、中心 `×3 → ×4`。

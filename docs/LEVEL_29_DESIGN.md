## 答题

- **A（4）**：`2×5 / 4×5 / 6×5 / 7×5`。
- **B（3）**：`5×3 / 5×4 / 5×6`；计数器按 5 递增（5 / 10 / 15 / 20…）。
- **C（3）**：纯听——只有扬声器 + 问号，无实物图无算式；`5×5 / 5×8 / 5×9`。

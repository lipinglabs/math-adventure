## 弯指的画法（§5.21）

- 十根手指等距排开（每手 5 根，间距 4px），弯第 n 根 = `digits[n-1]`。
- 弯下的那根 `scaleY(.34)` + `translateY(-4px)`，并**挪到 SVG 最后**（压在掌心之上）：
  整根藏进掌心只会留下一个说不清的缝，孩子分不出弯的是第几根。
- 弯指不参与计数、不点亮；左段橙、右段绿，逐个点亮（140 ms 间隔）。
- `9 × 9` 时右段为 0 根，靠「点不亮」自然表达「空」。

## 答题

- **A（4）**：`7×9 / 3×9 / 8×9 / 6×9`，弯指图 + `n × 9` 小标签 + 三键。
- **B（3）**：`6×9 / 5×9 / 9×9`，两个空（TENS / ONES），每个空只收本位数字，错数字回弹不记错。
- **C（3）**：三句里恰好一句错（`9×6=53`、`9×7=64`、`9×5=44`），答对后只翻结果格。

## 1. 教学目标

| 项 | 内容 |
|---|---|
| 认知目标 | 理解「合起来」就是加法；能把两组实物点数成总数 |
| 数量范围 | 两个加数都 ≥ 1，和 ≤ 5 |
| 题目覆盖 | 5 以内加法的全部 10 种有序组合，一种一题，不重复 |
| 前置知识 | 能数 1–5（不要求认数字符号） |
| 时长 | 教学约 75 秒 + 10 题约 3–4 分钟 |

设计取舍：第一关**不引入 0**（`0 + 3` 对 3 岁孩子是抽象跳跃），**不引入减法**，**不做拖拽**（点选对幼儿更稳）。

**交互**

| 事件 | 反馈 | 时序 |
|---|---|---|
| 点击选项（正确） | 键帽果冻抖动 + 金币音；两组实物滑到一起合并成一行并弹一下；星星迸发 + 高频 ting；进度点前进 | 650ms 后进下一题 |
| 点击选项（错误） | 键帽摇晃 + 柔和下行音；实物轻微变暗 200ms 后恢复；鼓励语音（限一次） | **不换题**，原地重做 |
| 点题干喇叭 | 重播题干语音 | 随时可用 |
| 10 题结束 | 进入结算 | — |

**为什么不用拖拽**：3 岁孩子的手指控制精度不足，点选命中率更高；拖拽留到第 3 关以后。

## 7. 技术实现要点

1. **新文件 `level-lv01.js`**，导出 `window.LEVELS[1] = { mount(stage, ctx), unmount() }`；`app.js` 在关卡 `status === 'ready'` 时优先调用它，找不到才回退到占位卡。
2. **实物全部内联 SVG**：苹果 / 气球 / 小鱼 / 星星各一个 `<symbol>`，用 `<use>` 复用；颜色走 CSS 变量。
3. **动画编排用 WAAPI**（`el.animate(...).finished`）串行，避免 `setTimeout` 猜时长；`prefers-reduced-motion` 时全部降级为淡入。
4. **运动预算**：任意时刻最多 5 个实物 + 3 个键帽 + 2 个特效 = 10，正好在上限内；超出由 `Engine.anim` 丢弃。
5. **卸载清理**：`unmount()` 必须 `cancel` 所有 WAAPI 动画、清空定时器、`Engine.audio.stop()`、移除 `stage` 子节点。
6. **音频**：题干播完才允许点选？不。点击选项立即 `Engine.audio.stop()` 打断题干，避免声音叠在一起。
7. **判定**：`Engine.session({total:10})`；答对调 `answer(true)`，答错调 `answer(false)`（题号不前进）；结束时按返回的 `star` 落盘。

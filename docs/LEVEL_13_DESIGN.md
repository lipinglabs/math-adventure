# Level 13 · Mix It Up（二阶大复习 · 综合点选）

> 第二阶段收官复习：把 **知识点 A（11–19）**、**B（不进位加法）**、**C（不退位减法）** 合成一关。
> 2 幕复习教学 + 10 题（顺序每局打乱），三种题型**全部是点数字键**，不拖拽、不限时。
> 教学重点只有两句：**加是合起来、减是拿走**；**永远先看个位**。

## 2. 教学分镜

### 第一幕：加与减的视觉对比（左右并排）

1. 两张对比卡同时弹入：左卡绿底 `+` 角标、右卡粉底 `−` 角标。
   每张卡从上到下是「一捆十块 → 一列零散积木 → 小算式」。
2. 左卡 12 = 一捆 10 + 2 块；右卡 18 = 一捆 10 + 8 块。**格位一次性建满**（左 5、右 8），
   后面的飞入 / 飞走只动自己，其余积木坐标不变（§5.7 / §5.11）。
3. `t1_a`：3 块积木从右上飞入左卡的空位，落地带 `scale(1.16,.74) → scale(.94,1.08) → scale(1)`
   的挤压回弹；说完结果位 `?` 弹成 **15**。
4. `t1_b`：右卡最后 5 块依次向上飘走并消散（间隔 90ms），只把自身 `visibility: hidden`，
   占位留在文档流里；说完结果位弹成 **13**。
5. 停 1 秒。`t1_c`：两张卡的算式里**只有个位数字转红并轻弹**（`12+3=15` 的 `2/3/5`、
   `18−5=13` 的 `8/5/3`），十位与运算符保持棕色——这是 §6.1「教学拆位」的落点。

### 第二幕：一个十 + 六个一 = 16

1. 十格阵（严格 2 行 × 5 列）装满 10 块，右侧 6 块零散积木。
2. `t2_a`：满十格亮起金色呼吸（`is-full`），6 块零散依次跳一下。
3. 停 1 秒 → 整组积木缩回中心淡出（`visibility: hidden` 保留占位），
   原地弹出 **104px 的纯数字 16**（弹入 + 一次 bounce）。
4. `t2_b`：「Let's see if you remember everything! Let's play!」→ 定格等点击。

## 3. 题型

### A / B · 纯算式点选（8 题）

- 屏幕中央 `13 + 4 = ?`（数字一律整块，不拆位），下方三个数字键。
- 点对：结果位立刻填上答案并转绿，金币 + 星星音，700ms 后进下一题。
- 点错：按键轻晃 + `try_again`（每题一次）+ 三个键重新排布（答案位置必变），停在原题。

### C · 看图选数（2 题）

- 十格阵（10 块全满）+ 右侧 4 或 8 块零散积木，下方三个数字键。
- 点对：十格阵加绿色描边（`is-right`）+ 金币音，700ms 后进下一题。
- 点错：同上，只重排数字，画面不动。

## 4. 实现要点

| 位置 | 做法 |
|---|---|
| 积木 | `.l13-cube` 尺寸由 CSS 变量 `--c` 决定（窄屏缩一档），`transform-origin: 50% 100%` |
| 格位 | `slotGrid(total, cols, filled)`：一次建满 `total` 个格位，**从底行往上**排（`grid-row` 显式指定），飞走只隐藏自身 |
| 飞入 | 先 append 再立刻 `animate`（`fill: both`），不会出现「先闪现再飞」 |
| 飞走 | 三段关键帧：原地 → 抬起 26px 并轻微放大 → 飘到 58px 并缩到 0.55 淡出；结束才 `visibility: hidden` |
| 拆位 | 教学算式用 `digitChip()` 把「12」拆成两个 `<i>`；答题用整块 `.l13-tile` |
| 满十 | 复用 `.tenframe` / `.tf-cell`（2×5、左上先填），格子里放 `.l13-cube` |
| 数字键 | `.l13-key` 92ms 过渡 + `:active` 下沉 5px（§5.12） |

## 5. 验收结果（2026-10-29）

- 语音 14 条关内 + 4 条公共，全部可解码，合计 **62.6 秒 / 490 KB**（关内 50.8 秒 / 398 KB）。
- 教学第一幕：格位 13 个（左 5 + 右 8）；飞入前左卡 2 块、飞入后 5 块；飞走后右卡可见 3 块；
  **所有格位 `dx = dy = 0`**；6 个个位数字 `rgb(201,80,74)`，其余保持 `rgb(107,78,49)`；
  两张卡算式分别为 `12+3=15` 与 `18−5=13`；定格 2.8 秒后出现手形提示。
- 教学第二幕：10 格全满 + 6 块零散；变数字前后格位 `dx = dy = 0`；大数字 `16`、字号 104px，原积木组 `visibility: hidden`。
- 10 题全对 → `gold`，`unlockedLevel = 14`；第 4 题故意点错 → 同题重做、题号不动（3 个圆点）、
  选项 `[18,19,17] → [17,19,18]`（答案 2→1），最终 `silver` 且不解锁（`unlockedLevel = 13`）。

  看图 2 题 14 / 18（零散 4 / 8）。
- 布局：390 与 375 宽都 `scrollWidth === innerWidth`；零 CJK（含 `aria-label`）。
- 地图：Stage 2 扩到 10 关后仍为 2 页（5 + 5），第 13 关在第 2 页最上面，标签 `Mix It Up`。
- 缓存：清空后首进读条（14 个音频 / 398 KB），二次进入 `voiceReqs = 0`、读条不出现。

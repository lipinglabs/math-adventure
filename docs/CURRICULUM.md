# CURRICULUM.md · 全游戏大纲（48 关）

> 来源：项目负责人提供的《李旻泽数学启蒙.docx》（2026-10-29）。
> 本文件是关卡内容的唯一事实来源；`levels_data.js` 只放已实现关卡的配置。
> 新增关卡前先核对本表，避免编号、名称、教学目标漂移。

---

## 0. 核心设定

| 项 | 内容 |
|---|---|
| 总量 | **5 大阶段，48 个关卡** |
| 语言 | 全英文沉浸（Allison 音色，语速 0.85） |
| 美术 | 纯代码 SVG / CSS 动画，**拒用外部大图**，不调生图接口 |
| 教学法 | 每个知识点用「**具象动画 → 场景互动 → 半抽象逻辑**」三种形态各学一遍（共 3 遍） |
| 节奏 | 教学模式必须**点屏幕推进**（每幕定格等点击） |
| 解锁 | **第一遍全对**才解锁下一关（金星）；有错则银星、不解锁 |

# CURRICULUM.md · 全课程大纲（48 关 · 五阶段）

> 本文件依据 `levels_data.js`（2026-10-31 实际配置）与 48 个 `level-lvNN.js` 反向整理。
> **本文件描述的是"已经实现"的内容**，不是计划。两者不一致时以代码为准，并回头修正本文件。

## 0. 核心设定

| 项 | 内容 |
|---|---|
| 总量 | **5 个阶段，48 关，全部实现** |
| 语言 | 全英文沉浸（Allison 音色，rate −15），界面零中文 |
| 美术 | 纯代码 SVG / CSS 动画，背景为每关一张固定照片（`assets/bg/bg_NN.jpg`） |
| 教学法 | 每关 1–4 幕教学：具象动画 → 场景互动 → 半抽象；教学幕一律**点屏幕推进** |
| 答题 | 每关固定 **10 题**，题型通常 3 种（4 / 3 / 3 分布），顺序每局打乱 |
| 选项数 | 遵循 §6.5：点选题 3 个、符号题 2 个、拖拽题无按钮 |
| 解锁 | 第一遍全对得**金星**并解锁下一关；有错得银星、不解锁 |
| 结业 | L15 / L27 / L39 三阶有结业仪式，L48 为全项目终极仪式 |

### 答题题型的三段式（贯穿全项目）

| 段 | 形态 | 说明 |
|---|---|---|
| A（4 题） | 具象点选 / 两段式操作 | 先动手（拖、点、分配），再点结果 |
| B（3 题） | 场景识别 | 听算式选画面 / 拖拽拼装 / 连线配对 |
| C（3 题） | 半抽象或找错 | 纯数字点选、五秒闪电、三选一挑错 |

> 例外：L48 按四类运算分配（3 / 3 / 2 / 2），L37 为单幕纯复习。

## 9. 验收口径（与本文件相关）

- 每关 **10 题**，题型分布与上表一致，顺序每局打乱。
- 教学幕数用 `grep -c "async function scene[A-Z]" level-lvNN.js` 复核。
- 语音键必须与 `voice/lvNN/` 下文件一一对应；调用前缀是 `lvNN/`（**不是 `lNN/`**）。
- 全英文：`document.body.innerText` 与 `aria-label` / `placeholder` 不得含 CJK。
- 文案与交互细节见 `PROJECT_MATH_RULES.md`（现行 v54，§8 验收条目 120 条）。
